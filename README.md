
# 📝 Notes App

A responsive Notes App built using HTML, CSS, and JavaScript. This application allows users to create, edit, delete, and manage multiple notes with custom titles. Notes are stored locally in the browser, so they remain available even after refreshing the page.

## ✨ Features

- Create multiple notes
- Add a custom title for each note
- Edit existing notes
- Delete notes
- Automatically save notes using Local Storage
- Search notes by title (if implemented)
- Responsive and user-friendly interface
- Clean and modern design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 📌 How to Use

1. Click **Add Note**.
2. Enter a note title.
3. Write your note content.
4. Save the note.
5. Edit or delete notes whenever needed.
